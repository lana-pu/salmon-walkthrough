Label on the left, value on the right, hairline between lines: facts and totals.

**Use** `<div class="kv"><span>Label</span><span>Value</span></div>` inside a Card padded 4 × 16. The label is `color-text-muted`, the value `color-text-text`, both `text-body` (14). Lines are `space-card-pad-lg` (16) tall-padded with a 1 `color-border-border` hairline between them.

**Total line:** set the line in 17 semibold (`font-size-17`, `font-weight-semibold`, `leading-snug`) and both sides in `color-text-text`, outside the card.

`kvl` gives roomier lines, `space-list-row-y` (24) above and below, for longer lists of facts.
