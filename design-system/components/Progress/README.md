**Segments.** `<div class="segments">` with `<span class="segment"><i style="width:40%"></i></span>` per stage: 6 tall (`size-progress-segment`), 4 apart, same track and fill as the light bar. Add `live` to the stage in progress for a moving shine. Used for the route to the meeting.
