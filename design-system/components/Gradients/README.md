Layered gradients from the Figma kit, one token each: `gradient-hero`, `gradient-ambient`, `gradient-feature`, `gradient-warm`, `gradient-plate`. Each layer reads tokens (the `glow-*` gradient colours and a few palette tones), so the preview rebuilds from the live tokens. In code, use `background-image: var(--gradient-hero); background-size: 100% 100%` on the element; never copy the layers into an element. Layer tables are in the Gradients section.
