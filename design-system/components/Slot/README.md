Round empty place for a person: someone you are waiting for, or a button to add someone.

**Use** `<span class="slot avatar--md">` with small Dots inside while waiting; `<button class="slot add avatar--md">` with a plus icon to add. The size comes from the same `avatar--*` class as the avatars next to it, so the row lines up.

**Anatomy.** Radius `radius-pill`, 1.5 dashed outline (`stroke-dashed`) in `color-border-dashed`; `add` fills `color-background-white`; icon in `color-icon`.
